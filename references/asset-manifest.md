# Public Asset Manifest

This public repository intentionally excludes the private demo media used in the original local project.

Add your own project media before generating a new video:

- character reference images
- restaurant scene images or video
- dish images or video
- voice references, if needed
- source short-video reference, if you are remaking a specific structure

Do not commit credentials, `.env` files, generated runtime databases, signed URLs, or private media unless you intend to publish them.

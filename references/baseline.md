# Public Baseline

The original local Skill contains a private demo pack with characters, restaurant media, dish media, voice references, and a finished V3 render.

This public release keeps the workflow, scripts, and Hypit templates, but does not include that private media pack. Use `prepare_project.py --mode new`, add your own assets, then update `material.svml`, `dialogue.svml`, and caption cues for the new project.

The intended video pattern is:

- a customer urges the restaurant to hurry a dish
- the owner misunderstands the request literally
- the owner cheers for the dish with repeated energetic lines until the ending
- subtitles use top-centered white text with a light shadow and no black backing box

For private reuse of the original demo V3, install the complete local asset pack outside the public repository.

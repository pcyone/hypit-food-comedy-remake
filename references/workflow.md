# 制作与返修

## 环境和本地准备

检查现有Hypit、ffmpeg、ffprobe、Python/Pillow，复用已装工具，不因调用Skill重装环境。准备脚本优先选择本机已验证的Node22 Hypit路径，缺失才用PATH中的Hypit；失败时按当前Hypit环境文档修复，不默默安装大模型。

`prepare_project.py --mode reuse --output <新目录>` 恢复已有成片及源；`--mode new` 只准备参考和可改写请求。两者都不调用云端。新目录使用 `sh hypit-local.sh ...`。

复用模式有：`output/final-v3.mp4`、无字幕无声 `output/picture-clean.mp4`、完整 `output/voice-master.wav`、烧录字幕且物理无声的 `output/review-picture-silent.mp4`、`analysis/cues-v3.json`。新作须生成/合成后再建立预览素材，不能把缺文件的review说成可播放结果。

Studio源支持画面与声音编排；保存的预览字幕已烧录。改字幕时编辑`analysis/cues-v3.json`，用`output/picture-clean.mp4`重新合成，再更新无声预览，不能在已有字幕上重复叠字。

## 拆解、映射、生成

先提取催菜、老板困惑、最后鼓劲的节拍和镜头；把声音/对白与连续帧一起看。ASR零时长尾词或漏词不等于没说话。

原男顾客→歪博云，老板→克托炎，包子→酿豆腐，街边摊→用户餐厅。新菜改变名词、烹饪动词和食物参考；新餐厅修改场景参考与描述；只改配音则保留画面。

`material.svml` 已据返修经验改写为四遍喊到片尾，并带男女声参考。这是新作生成请求模板，尚未作为新镜头生成验收；必须随新资料修改。角色表多角度是一个身份。含人物的图/视频声明person-reference=true，食物/空餐厅false，音频不填。核对当前模型参考数量、长度及组合限制。

```sh
sh hypit-local.sh check material.svrun
sh hypit-local.sh plan material.svrun
sh hypit-local.sh pricing material.svrun --json
```

按当前账户、真实请求和本次价格核定范围；旧74.75积分许可不延伸到新片或重抽。已有本轮授权不重复问；历史免费以本次查询为准。将本次范围/预算写到项目BRIEF后，授权范围内 `build <run> --follow`，记录回执。观察断开先查状态/inspect，禁止盲目再次build。

新项目模板不引用旧Build。原项目返修用明确Run Candidate或导出的本地素材保留无关部分。沙盒无法访问系统凭据时先区分权限与认证失效，请求必要权限，不读取或显示密钥，不绕过权限边界。

## 配音、激情和口型

优先生成对白/嘴型/拍手一起表演。检查输出是否误念包子或串台。需要后配音时，`dialogue.svml` 从普通音频资源读取既有男女声参考，无需重建声线。仅返修结尾时把Run目标限制到cheer-a/cheer-b，保留前五句。

本案较稳定方式是**两个短请求、各喊两遍**；曾用四遍长指令得到34秒重复声音。异常先核对已生成内容，只使用有效部分，不把多余语音塞进13秒或无限重试。

已用指令：

> 同一男声，兴奋地放声大喊，像比赛现场拼命给队友加油！胸腔发力，明亮高亢，短促有冲劲，强烈重读加油。两句快速连贯，每句约一秒，只读正文。

> 同一男声，热血沸腾地高声呐喊，越喊越激动！重音爆发，声音向前冲，像在场边用力拍手助威。两句快速连贯，每句约一秒，结尾干脆有力，只读正文。

整句保留辅音起音和尾音，先删明确长静音的中部，再按实际画面排句。必要的小幅保音高变速需明确记录；V3的0.85/0.90不适用于任意新声音。最后一遍“油”不能因时长被截掉：调整句长/前停顿，或在用户允许时改片长，不能用字幕代替缺声。

保留用户认可前段时复制PCM前缀并核查相同。统一48kHz，重采样后重置时间戳，按采样数制作完整母带。其他音效须明确来源及时间，不能混回生成原对白。音量增加不等于激昂表演，时序对齐不等于逐字口型重建。

## 合成与预览

`finalize.py` 先物理去声，再叠顶部白字阴影和挂唯一母带；画面不能已有重复字幕，输出用新版本文件名。可 `--font` 指定中文字体；脚本无生成/自动变速/猜测配音功能。

`review.svml` 的视频Normalize audio=none，Film只选画面visual和一条母带。改路径后检查实际预览素材，不能只看文件写入。预览可归一化为双声道；需要对照时比较解码波形/时间，不能仅凭文件hash不同认定旧声音。

使用空闲端口 `sh hypit-local.sh studio --run review.svrun --port <端口>`，不要关闭其他任务的服务占端口。打开打印出的 `#comments` 地址。检查导出文件与页面都加载新版本，交付真实MP4；机器检查不能代替激情、顺畅度和嘴型自然度的观看试听。
